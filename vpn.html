⚡ Relay Backend Setup

TunnelX uses a Cloudflare Worker as a relay to test proxies and fetch pages. It's free (100K requests/day) and takes 2 minutes to set up.

1 Go to workers.cloudflare.com → Sign up free
2 Dashboard → Workers & Pages → Create Worker
3 Name it tunnelx-relay → click Deploy
4 Click Edit Code → paste the Worker script → Save & Deploy
5 Copy your Worker URL below
This is the URL from step 5. It looks like https://tunnelx-relay.xxxxx.workers.dev
